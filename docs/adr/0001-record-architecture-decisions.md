# ADR-0001: Record architecture decisions

- **Status:** Accepted
- **Date:** 2026-10-04
- **Deciders:** @jkose002, @Swahilipot-Hub-Engineering/maintainers

## Context

This project will be built and maintained by a rotating group of volunteers, interns and
community contributors at Swahilipot Hub. Without a written record of *why* the
system is the way it is, decisions get re-argued from scratch, and new contributors
cannot tell the difference between a deliberate choice and an accident.

## Decision

We record significant architectural decisions as **Architecture Decision Records** (ADRs)
in `docs/adr/`.
